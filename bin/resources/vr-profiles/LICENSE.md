# VR profile licensing

## These files are DATA, not part of the emulator

The per-game VR profiles in this folder (`*.yaml`) are original works of
**Patrick Carey** (<patrickfcarey@gmail.com>), authored from scratch. They are
tuning and measurement data that the emulator *reads at runtime* — they are
**not** program code, **not** derived from PCSX2, and **not** derived from any
game. Like a configuration file, a save file, or a texture pack, each profile
is a separate work that happens to be consumed by the emulator: the emulator's
GPL-3.0 license covers the *program*, not this *data*.
